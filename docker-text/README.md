## この本の位置づけ

ここまでの3冊で、あなたは**3回の環境構築**を経験しています。

- Node.js を入れて、バージョンを確認して、PATH に悩んだ
- Python を入れて、venv を作って、pip でパッケージを入れた
- 「自分の環境では動くのに」という状況に、一度は遭遇したはず

**Docker は、この苦しみを根本から解決する道具です。**

この本を終えると、**コマンド1つでアプリ一式が起動する**状態が作れます。
5冊目の MySQL も、Docker があれば環境構築が一瞬で終わります。

> **なぜ4冊目なのか**
> Docker を最初に教えると「便利そうだけど、何が嬉しいのかわからない」で終わります。
> **3回の環境構築で苦労したあとだからこそ**、Docker の価値が実感できます。
