## この本の位置づけ

1冊目でフロントエンド（ブラウザ側）、2冊目で Python を学びました。
この本では、**バックエンド（サーバー側）**を作ります。

これまでは「自分のパソコンの中だけで動くもの」を作ってきました。
この本を終えると、**複数の人が同じデータを見られるアプリ**が作れるようになります。

最終的に、**1冊目で作った React のアプリと、この本で作った API を接続します。**

## この本の前提

- **python-text を読み終えていること（必須）**
- react-text を読み終えていること（推奨。第9章で React と接続します）
