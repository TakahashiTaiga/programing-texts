# AI への質問テンプレート集（学習者用）

つまずいたときに、そのままコピーして使えるテンプレートです。
**`<>` の部分を自分の状況に書き換えて**、AI に送ってください。

質問がうまいほど、返ってくる答えの質が上がります。
最初はこのテンプレートをそのまま使ってください。

---

## 0. 最初の1回だけ（学習開始時）

```
これから下記のテキストでプログラミングを学びます。
まず次の URL を読んで、この指示に従って私をサポートしてください。

https://github.com/TakahashiTaiga/programing-texts/blob/main/ai/instructions.md

私の環境:
- OS: <Windows 11 / macOS / Ubuntu など>
- プログラミング経験: なし
- いま読んでいるテキスト: <react-text / python-text など>
```

---

## 1. エラーが出た

```
<react-text> の <2.2.1> で詰まりました。

【やろうとしたこと】
<例：npm run dev で開発サーバーを起動しようとした>

【実行したコマンド or 書いたコード】
```
<ここにそのまま貼る>
```

【出たエラー（全文）】
```
<ここにそのまま貼る。省略しないこと>
```

【環境】
OS: <Windows 11>
```

> **コツ**：エラーは**全文をそのまま**貼ってください。
> 「なんかエラーが出ました」だけでは AI も推測しかできません。
> 長すぎても大丈夫です。

---

## 2. エラーは出ないが、思ったとおりに動かない

```
<react-text> の <7.3> をやっています。

【期待していた動き】
<例：ボタンを押すと数字が 1 増える>

【実際の動き】
<例：ボタンを押しても数字が変わらない。エラーは出ていない>

【いま書いているコード】
```
<ファイル名も添えて貼る>
```
```

---

## 3. 演習問題が解けない

```
<react-text> の演習 <5.3> が解けません。

【問題】
<問題文をコピー>

【自分で考えたこと】
<例：ループで1件ずつ見ればいい気がするが、条件の書き方がわからない>

【ここまで書いたコード】
```
<書きかけでOK。何も書けていないなら「まだ書けていません」と書く>
```

答えではなく、まずヒントをください。
```

> **コツ**：「答えではなくヒントを」と書くと、いい距離感で返ってきます。
> どうしても無理なら「3回試したのでもう答えを見たいです」と伝えてください。

---

## 4. 説明の意味がわからない

```
<react-text> の <4.5.2> の説明が理解できません。

【わからない部分】
<テキストの該当箇所をコピー>

【自分の理解】
<例：ループが繰り返すのはわかるが、i++ が何をしているのかわからない>

プログラミング未経験なので、身近なたとえで説明してもらえますか。
```

---

## 5. 環境構築でつまずいた

```
<react-text> の <1.4> の環境構築で止まりました。

【OS】<Windows 11 / macOS Sonoma (M2) / Ubuntu 22.04>
【やったこと】<手順どおり Node.js をインストールした>
【結果】
```
<コマンドの出力やエラーを全部貼る>
```

【確認済み】
- <node --version は実行できた / できなかった>
```

> **コツ**：環境系のトラブルは**あなたのせいではありません**。
> 遠慮なく AI に全部やってもらってください。ここは学習範囲外です。

---

## 6. 自分のコードをレビューしてほしい

```
<react-text> の <10章> の課題ができました。

【課題】<課題文>
【書いたコード】
```
<全部貼る>
```

<10章>までの学習範囲内で、直したほうがいい点を教えてください。
先の章の内容（まだ習っていないこと）は今は不要です。
```

---

## 7. 「なぜこう書くのか」が納得できない

```
<react-text> の <7.2> で、state を直接書き換えてはいけない理由が納得できません。

count = count + 1 ではダメで、setCount(count + 1) にする理由を
プログラミング未経験でもわかるように説明してください。
```

> **コツ**：「納得できない」と正直に言うのは、とても良い質問の仕方です。
> 丸暗記より理解のほうが、あとで効いてきます。

---

## 8. 復習したい / 進捗を確認したい

```
<react-text> の <1章から5章まで> を終えました。
理解できているか確認したいので、この範囲から確認問題を5問出してください。
答えは私が答えてから教えてください。
```

```
<react-text> を <7章> まで進めました。
ここまでで身についているはずのことを一覧で整理してください。
```

---

## 9. 学習が進まない・モチベーションが落ちた

```
<react-text> の <8章> でずっと詰まっていて、進む気力が落ちています。
いまの理解度でも進められる方法や、いったん飛ばしていい箇所があれば教えてください。
```

> テキストは順番どおりに読むのが理想ですが、詰まり続けるより
> **一度飛ばして先に進み、あとで戻る**ほうが結果的に早いことがあります。
> AI に「ここは飛ばしていいか」を聞いてみてください。

---

## 質問がうまくなるための3原則

1. **章番号を書く** — AI が「いまのあなたのレベル」を把握できます
2. **エラーは全文を貼る** — 省略した部分に答えがあることが本当によくあります
3. **自分がやったことを書く** — 「何も試していない」場合も、そう書いてください
