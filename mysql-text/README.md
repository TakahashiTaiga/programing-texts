## この本の位置づけ

**データベースは、Web アプリの心臓部です。**

ここまでのテキストでも少しデータベースに触れてきましたが、
この本では**データベースそのもの**を正面から扱います。

- どうやってデータを取り出すのか（SQL）
- どうやってテーブルを設計するのか
- なぜ検索が遅くなるのか、どう直すのか

この本を終えると、**フェーズ1「作れるようになる」が完了**します。
React + FastAPI + MySQL を Docker で動かす Web アプリを、一人で作れる状態です。
