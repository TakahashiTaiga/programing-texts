## この本の位置づけ

1冊目の React では、**画面を作りながら**プログラミングの基礎を学びました。
この本では、**汎用のプログラミング言語である Python** で、
同じ概念（変数・条件分岐・繰り返し・関数）をもう一度別の形で学び直します。

> **なぜ同じことをもう一度やるのか**
> 「JavaScript ではこう書いたことを、Python ではこう書く」と対比することで、
> **言語ごとの書き方の違い**と**言語によらない共通の考え方**が区別できるようになります。
> これができると、3つ目以降の言語の習得が一気に速くなります。

この本のあと、3冊目の FastAPI でサーバー側の開発に進みます。

## この本の前提

- react-text を読み終えていること（**必須ではありませんが、強く推奨します**）
- ターミナルの基本操作（[react-text 1.4](../react-text/01-web-and-environment.md)）

react-text を読んでいない場合は、
**react-text の第0章と第1章だけ先に読んでください。**
AI サポートの準備とターミナルの操作は、この本でも必要になります。
