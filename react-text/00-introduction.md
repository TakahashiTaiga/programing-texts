# 第0章 はじめに

この章は、**必ず最初に読んでください。**

とくに [0.2 AI サポートの準備](#02-ai-サポートの準備) は、
このテキストで最も大事な準備です。ここを飛ばすと、
本来なら 3 分で解決する問題に 3 時間かかることになります。

## この章で学ぶこと

- このテキストが誰のためのもので、何ができるようになるかを理解する
- 学習をサポートしてくれる AI をセットアップする
- 詰まったときにどう動けばいいかを知る
- このテキストの読み方（記号の意味）を知る

## 0.1 このテキストについて

### 0.1.1 対象読者

**プログラミングを一度もやったことがない人**を対象にしています。

前提として必要なのは、次のことだけです。

- パソコンの電源を入れて、ブラウザで検索ができる
- ファイルを保存したり、別の場所に移動したりできる
- 文字を入力できる

逆に、次のことは**まったく知らなくて大丈夫**です。すべてこのテキストで説明します。

- 「ターミナル」「コマンド」が何なのか
- 「ディレクトリ」「パス」「拡張子」が何なのか
- 変数、関数、配列……といったプログラミングの用語

すでに他の入門書で挫折した経験がある方も対象です。
このテキストは、**挫折の最大の原因である「環境構築」と「原因のわからないエラー」を
AI に肩代わりさせる**設計になっています。

### 0.1.2 このテキストを終えると何ができるようになるか

最終的に、次のようなものを**自分の手で**作れるようになります。

- ブラウザで動く、見た目の整った Web ページ
- 入力・追加・削除ができる、動きのあるアプリ（タスク管理アプリを作ります）
- 外部からデータを取ってきて表示するページ

途中で身につく力は次のとおりです。

| 章 | 身につくこと |
|----|------------|
| 第1章 | Web の仕組み、開発環境、ターミナルの基本操作 |
| 第2章 | HTML（Web ページの構造を作る） |
| 第3章 | CSS（見た目を整える） |
| 第4〜5章 | JavaScript（プログラミングそのもの） |
| 第6〜9章 | React（部品を組み合わせてアプリを作る） |
| 第10章 | 実際に1つのアプリを完成させる |

**第4章と第5章がこのテキストの山場です。**
ここで学ぶ「変数」「条件分岐」「繰り返し」「関数」は、
React だけでなく、これから学ぶすべての言語で使う共通の土台になります。

### 0.1.3 全5冊の中での位置づけ

このテキストは、**プログラミング未経験から Web エンジニアになるまでの全5冊**の1冊目です。

| # | テキスト | 内容 |
|---|---------|------|
| **1** | **React（この本）** | **Web の仕組み、HTML、CSS、JavaScript、React** |

> また、React を学ぶ過程で Web の仕組み・HTML・CSS・JavaScript が
> まとめて身につくため、効率も良いです。

## 0.2 AI サポートの準備

**この節がこのテキストで最も重要です。**

### 0.2.1 なぜ AI を使うのか

プログラミングの独学で人が挫折する原因は、だいたい次の2つです。

**1. 環境構築で詰まる**

本のとおりにやったのに、なぜかインストールできない。
コマンドを打ったら「そんなコマンドはありません」と言われる。
検索しても、出てくる記事は3年前のもので、書いてあるとおりにやっても動かない。

**これは、あなたの能力とはまったく関係ありません。**
使っている OS、バージョン、インストール済みの他のソフト……
無数の組み合わせがあり、本にすべてを書くことは物理的に不可能なのです。

**2. エラーの意味がわからない**

赤い英文が大量に出てきて、何が起きているのか見当もつかない。
経験者なら 1 行読んだだけで原因がわかるものでも、
未経験者にとっては「何がわからないのかもわからない」状態になります。

---

この2つは、**生成 AI が非常に得意とする領域**です。
あなたの環境で起きているエラーを貼り付ければ、
あなたの状況に合わせた手順を出してくれます。

このテキストは、**AI がそばにいることを前提**に書かれています。
「詰まったら AI に聞く」を、遠慮せずやってください。

> **ただし、何でも AI に聞けばいいわけではありません**
> ロジックを考える部分まで AI に任せると、いつまでも自分で書けるようになりません。
> そこで、**この後セットアップする指示ファイル**が効いてきます。
>
> このファイルを読み込ませた AI は、
> **「考える価値のあることは考えさせ、考える価値のないことは全部やってくれる」**
> という振る舞いをします。

### 0.2.2 使う AI を決める

**普段から使っている AI があれば、それを使ってください。**
ChatGPT、Claude、Gemini、Copilot、Codex ——— どれでも構いません。
使い慣れているものがいちばんです。

**特に決まっていない場合は、次のどちらかをおすすめします。**

| AI | 特徴 | 向いている人 |
|----|------|------------|
| **Claude**（claude.ai） | 長い文章の指示をよく守る。コードの説明が丁寧 | ブラウザで手軽に始めたい人 |
| **Codex**（OpenAI） | 手元のファイルを直接読んで直せる | あとから本格的に使い込みたい人 |

どちらも無料で始められます。**まずはブラウザで使えるものを1つ用意してください。**

> **補足：AI にコードを書かせることについて**
> 「AI に頼ると身につかないのでは」と心配になるかもしれません。
> このテキストで用意した指示ファイルは、まさにその心配に対応するために作ってあります。
> AI は演習問題の答えを教えてくれません。ヒントだけを、段階的に出してくれます。

### 0.2.3 指示ファイルを読み込ませる

**学習を始める前に、1回だけやる作業です。**

選んだ AI を開いて、次の文章をそのままコピーして送ってください。
`<>` の中だけ、自分の環境に書き換えます。

```text
これからプログラミングを学びます。
まず次の URL のドキュメントを読んで、その指示に従って私をサポートしてください。

https://github.com/TakahashiTaiga/programing-texts/blob/main/ai/instructions.md

私の状況:
- OS: <Windows 11 / macOS / Ubuntu など>
- プログラミング経験: なし
- 読んでいるテキスト: react-text（プログラミング未経験から始める React）
```

> **AI が URL を読めない場合**
> 一部の AI は、URL からファイルを読み込めないことがあります。
> その場合は、上記の URL をブラウザで開いて、
> **中身をすべてコピーして AI に貼り付けて**ください。
> 「以下のドキュメントの指示に従ってください」と一言添えれば同じ効果があります。

### 0.2.4 動作確認

準備ができたか確かめましょう。AI に次のように聞いてみてください。

```text
確認です。私が「演習問題が解けません」と言ったら、あなたはどう対応しますか？
```

**期待する答え**（言い回しは AI によって違います）

> まずヒントを段階的に出します。いきなり完成コードはお見せしません。
> 一方で、環境構築やインストールのエラーなど、学習内容と関係ない部分は
> 手順を全部お出しして解決します。

このような答えが返ってきたら、準備完了です。

もし「はい、コードを書きます」のような答えが返ってきたら、
指示ファイルがうまく読み込まれていません。
0.2.3 をもう一度、今度は**中身をコピー&ペーストする方法**で試してください。

## 0.3 学習の進め方

### 0.3.1 必ず手を動かす

**読むだけでは絶対に身につきません。**

このテキストに出てくるコードは、**すべて自分でタイプして**ください。
コピー&ペーストではなく、手で打つことをおすすめします。

理由は3つあります。

1. **打ち間違いからエラーの読み方を学べる**
   エラーは敵ではなく、いちばんの先生です
2. **手が構文を覚える**
   考えなくても `function` と打てるようになるまでには、回数が必要です
3. **読み飛ばしができない**
   打つには読むしかありません

> 20 行を超える長いコードは、コピーしても構いません。
> ただし**コピーしたあと、1 行ずつ何をしているか確認**してください。

### 0.3.2 詰まったときの動き方

詰まったら、次の順番で動いてください。

**ステップ1：3分だけ自分で考える**

- エラーメッセージを**日本語に訳してみる**（AI に訳させてもよい）
- 打ち間違いがないか、コードを上から眺める
- 直前に何を変えたか思い出す（**動いていた状態から何を変えたか**が最大の手がかりです）

**ステップ2：AI に聞く**

3分考えてわからなければ、すぐ AI に聞いてください。粘る必要はありません。

質問するときは、**章番号を必ず添えて**ください。

```text
react-text の 2.3.4 で詰まりました。

【やろうとしたこと】
画像を表示しようとした

【書いたコード】
<img src="images/cat.png">

【結果】
画像が表示されず、壊れたアイコンが出る

【環境】
OS: Windows 11
```

**章番号を伝えることが重要です。**
AI は「この人は 2.3.4 にいる＝まだ CSS も JavaScript も知らない」と判断して、
あなたが理解できる範囲の言葉で答えてくれます。

質問のテンプレートは
[`ai/prompt-templates.md`](https://github.com/TakahashiTaiga/programing-texts/blob/main/ai/prompt-templates.md)
にまとめてあります。コピーして使ってください。

**ステップ3：それでも進まなければ、飛ばす**

同じところで 30 分以上止まったら、いったん飛ばして先に進んでください。
先の章を読んでから戻ると、あっさり解決することがよくあります。

### 0.3.3 理解度チェックと演習問題

各章の最後に2種類の問題があります。

**理解度チェック**
読んだ内容を思い出せるか確認する問題です。3〜6問あります。
すぐ答えられなければ、その節をもう一度読んでください。

**演習問題**
実際に手を動かして作る課題です。難易度を★で示しています。

| 表示 | 意味 |
|------|------|
| ★☆☆ | 本文のコードを少し変えればできる |
| ★★☆ | 本文の複数の内容を組み合わせる必要がある |
| ★★★ | 自分で調べたり設計したりする必要がある |

**答えは本の最後の「解答編」にまとめてあります。**

> **解答編の使い方**
> いきなり見ないでください。**最低でも1回は自分で書いてみてから**見てください。
> 「わからない」と思っても、まず AI にヒントをもらって、もう一度試すのが理想です。
>
> どうしても解けなかった問題は、解答編を読んだあと、
> **何も見ずにもう一度自分で書き直して**ください。これで定着します。

### 0.3.4 ペースの目安

急ぐ必要はありませんが、目安を示しておきます。

| 進め方 | 1日の学習時間 | 完走の目安 |
|--------|-------------|-----------|
| 仕事の後に少しずつ | 1時間 | 約2〜3か月 |
| 週末にまとめて | 週8時間 | 約2〜3か月 |
| 集中して取り組む | 1日5時間 | 約3〜4週間 |

**大事なのは、間隔を空けすぎないこと**です。
週1回より、毎日15分のほうが確実に進みます。

1週間以上空いてしまったら、AI にこう聞いてください。

```text
react-text を <3章> まで読んで、1か月空いてしまいました。
再開する前に、ここまでの要点を10行くらいで振り返らせてください。
```

## 0.4 このテキストの表記ルール

### コードの示し方

コードブロックの上に、**どのファイルに書くか**を示します。

`index.html`

```html
<h1>こんにちは</h1>
```

ファイルの一部だけを変更する場合は、その旨を書きます。

> `index.html` の `<body>` の中を、次のように変更します。

### 実行結果

コードを動かすと何が起きるかを示します。

```text
実行結果:
こんにちは
```

### コマンド

ターミナルに打ち込むコマンドは、**OS ごとに分けて**示します。

**Windows（PowerShell）**

```powershell
node --version
```

**macOS / Linux**

```bash
node --version
```

自分の OS のほうだけを見てください。
コマンドの先頭に `$` や `>` は付けていないので、**そのままコピーできます**。

### 囲み記事

4種類あります。

> **補足**
> 読み飛ばしても先に進めます。興味があれば読んでください。

> **注意**
> 守らないと動きません。必ず読んでください。

> **よくある間違い**
> 多くの人がここでつまずきます。先回りして知っておくと得です。

> **つまずいたら**
> AI に相談するときの、そのまま使える質問文です。

### 章番号

すべての項に `2.3.4` のような番号が振ってあります。

**この番号を AI に伝えることが、このテキストの使い方の要です。**
「2.3.4 で詰まりました」と言うだけで、AI があなたの現在地を把握してくれます。
