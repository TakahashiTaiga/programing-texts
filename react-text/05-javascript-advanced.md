# 第5章 JavaScript の基礎（後半）

> 🚧 **この章は執筆中です。**
> 以下は予定している章立てです。

第4章で「1つの値」を扱えるようになりました。
この章では**複数の値をまとめて扱う方法**と、
**時間のかかる処理を待つ方法**を学びます。

React に進むために必要な JavaScript は、この章で出そろいます。

## この章で学ぶこと（予定）

- 配列とオブジェクトで、複数のデータをまとめて扱えるようになる
- `map` / `filter` / `reduce` で配列を加工できるようになる
- 非同期処理を理解し、サーバーからデータを取得できるようになる
- ファイルを分割して、必要なものだけ読み込めるようになる
- JavaScript から HTML を操作できるようになる

## この章の前提

- [第4章](./04-javascript-basics.md) の変数・条件分岐・繰り返し・関数
