# 第7章 props と state

> 🚧 **この章は執筆中です。**
> 以下は予定している章立てです。

React の中核です。ここを理解すれば、React でアプリが作れるようになります。

## この章で学ぶこと（予定）

- props でコンポーネントに値を渡せるようになる
- state で「変化する値」を扱えるようになる
- ボタンのクリックなどのイベントを処理できるようになる
- 配列からリストを表示できるようになる
- 条件によって表示を切り替えられるようになる
- フォームの入力を React で扱えるようになる
