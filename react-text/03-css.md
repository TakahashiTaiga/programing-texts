# 第3章 CSS — 見た目を整える

前の章で作ったページは、機能としては正しいものの、
見た目はそっけないままです。

この章では **CSS** を学び、色・余白・レイアウトを自分で組み立てられるようにします。
とくに **3.5 のレイアウト（Flexbox）** は、
「要素を横に並べる」という Web 制作でいちばん使う技術です。

## この章で学ぶこと

- CSS のルールの構造（セレクタ・プロパティ・値）を説明できるようになる
- class を使って、狙った要素にスタイルを当てられるようになる
- ボックスモデルを理解し、余白を意図どおりに作れるようになる
- Flexbox で要素を横に並べ、中央揃えができるようになる
- スマホでも崩れないページを作れるようになる
- CSS が効かないときの原因を自分で調べられるようになる

## この章の前提

- [第2章](./02-html.md) の HTML が書けること
- 開発者ツール（F12）を開けること

> **つまずいたら**
> CSS は「書いたのに効かない」が最も多い分野です。
> **[3.7](#37-css-が効かないときの調べ方) に原因の調べ方をまとめてあります。**
> それでも解決しなければ、章番号・HTML・CSS の3つを AI に貼り付けてください。

## 3.1 CSS の書き方

### 3.1.1 CSS とは

**CSS**（Web ページの見た目を指定するための言語）は、
**C**ascading **S**tyle **S**heets の略です。

HTML が「これは見出しである」と**意味**を決めるのに対し、
CSS は「見出しはオレンジ色の 32 ピクセルで表示する」と**見た目**を決めます。

```text
HTML: <h1>ネコカフェ にゃんこ</h1>   ← これは大見出しだ
CSS:  h1 { color: orange; }          ← 大見出しはオレンジ色で
```

**なぜ分けるのか**

見た目の指定を HTML の中に直接書くこともできます。しかし、そうすると：

- 見出しが 50 個あるページで色を変えたい → **50 箇所直す**
- ページが 20 枚あるサイトで色を変えたい → **20 ファイル × 50 箇所**

CSS を分けておけば、**1 箇所直すだけで全部に反映されます。**

### 3.1.2 HTML から CSS を読み込む

CSS の書き方は3通りありますが、**この本では3番目だけを使います。**

**方法1：`style` 属性（インラインスタイル）**

```html
<h1 style="color: orange;">タイトル</h1>
```

その要素だけに適用されます。**使わないでください。**
上で説明した「まとめて直せる」という利点が失われます。

**方法2：`<style>` タグ**

```html
<head>
  <style>
    h1 { color: orange; }
  </style>
</head>
```

そのファイル内だけで有効です。他のページには適用されません。

**方法3：別ファイルにする（この本ではこれを使います）**

`style.css` という別のファイルを作り、HTML から読み込みます。

`style.css`

```css
h1 {
  color: orange;
}
```

`index.html`

```html
<head>
  <meta charset="UTF-8" />
  <title>ネコカフェ にゃんこ</title>
  <link rel="stylesheet" href="style.css" />
</head>
```

| 属性 | 意味 |
|------|------|
| `rel="stylesheet"` | 「これはスタイルシートです」という宣言 |
| `href="style.css"` | CSS ファイルの場所（相対パス。2.3.4 参照） |

> **注意：`<link>` は `<head>` の中に書く**
> `<body>` の中に書いても動くことがありますが、
> **表示が一瞬崩れる**などの問題が起きます。必ず `<head>` の中に書いてください。

**やってみましょう**

`react-lesson` に `css-practice.html` と `style.css` の2つを作ってください。

`css-practice.html`

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>CSS の練習</title>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <h1>ネコカフェ にゃんこ</h1>
    <p>営業時間は 10:00 - 20:00 です。</p>
  </body>
</html>
```

`style.css`

```css
h1 {
  color: orange;
}
```

ブラウザで `css-practice.html` を開いて、見出しがオレンジ色になっていれば成功です。

> **オレンジにならなかったら**
> 3.7 を先に読んでください。原因はだいたい次の3つです。
> - `<link>` のパスが間違っている
> - CSS ファイルの保存を忘れている
> - `<link>` を `<head>` の外に書いている

### 3.1.3 ルールの構造

CSS の1つのかたまりを**ルール**と呼びます。

```css
h1 {
  color: orange;
  font-size: 32px;
}
```

分解すると、こうなります。

```text
h1 {                    ← セレクタ（どの要素に適用するか）
  color: orange;        ← 宣言（プロパティ: 値;）
  font-size: 32px;      ← 宣言
}
```

| 名前 | 意味 | 例 |
|------|------|-----|
| **セレクタ** | どの要素に適用するか | `h1` |
| **プロパティ** | 何を変えるか | `color` |
| **値** | どう変えるか | `orange` |

**書き方のルール**

1. セレクタの後ろは `{` `}` で囲む
2. プロパティと値の間は `:`（コロン）
3. **各行の最後は `;`（セミコロン）**
4. スペースや改行は自由（読みやすさのため）

> **よくある間違い：セミコロンの書き忘れ**
> ```css
> h1 {
>   color: orange     ← ; がない
>   font-size: 32px;  ← この行も効かなくなる
> }
> ```
> セミコロンを忘れると、**その行だけでなく次の行も効かなくなります。**
> 「なぜか一部だけ効かない」ときは、まず `;` を確認してください。

**コメント**

```css
/* これはコメントです */
h1 {
  color: orange; /* 見出しはオレンジ */
}
```

CSS のコメントは `/*` と `*/` で囲みます。
HTML の `<!-- -->` とは違うので注意してください。

## 3.2 セレクタ

「どの要素に適用するか」を決めるのがセレクタです。ここが CSS の要です。

### 3.2.1 要素セレクタ

タグ名をそのまま書くと、**そのタグすべて**に適用されます。

```css
p {
  color: gray;
}
```

ページ内のすべての `<p>` が灰色になります。

```css
body {
  background-color: #f5f5f5;
}
```

`<body>` に適用すれば、ページ全体の背景色を変えられます。

> **要素セレクタは「全体の基本設定」に使う**
> 「すべての段落の行間を広げる」「すべてのリンクの色を変える」のように、
> **例外なく全部に効かせたいとき**に使います。
>
> 個別に指定したいときは、次の class セレクタを使います。

### 3.2.2 class セレクタ

**実務でいちばん使うセレクタです。**

HTML 側で `class` を付けます。

```html
<p class="note">※駐車場はありません</p>
<p class="note">※予約優先制です</p>
<p>通常の段落です。</p>
```

CSS 側では、class 名の前に **`.`（ドット）** を付けます。

```css
.note {
  color: red;
  font-size: 14px;
}
```

`class="note"` が付いた要素だけが赤くなります。3つ目の `<p>` は変わりません。

**同じ要素に複数の class**

```html
<p class="note important">※重要なお知らせ</p>
```

```css
.note {
  font-size: 14px;
}

.important {
  font-weight: bold;
}
```

**両方のルールが適用されます。** 小さくて太い文字になります。

> **これが CSS の設計の基本です**
> 「小さい文字」「太字」「赤色」のような**部品を作っておき、
> 必要な組み合わせを HTML 側で選ぶ**、という考え方をします。

**特定のタグの、特定の class に絞る**

```css
p.note {
  color: red;
}
```

`<p class="note">` にだけ適用されます。
`<div class="note">` には適用されません。

> **ただし、これはあまり使いません**
> `.note` とだけ書いておいたほうが、あとでタグを変えたときに壊れません。
> **基本は `.note` の形で書いてください。**

### 3.2.3 id セレクタ

`id` を指定するときは **`#`（シャープ）** を使います。

```html
<div id="header">...</div>
```

```css
#header {
  background-color: navy;
}
```

**ただし、CSS で `id` セレクタを使うのは避けてください。**

理由は次の 3.2.5 で説明する「詳細度」です。
`id` は非常に強く、あとから上書きするのが困難になります。

> **実務での使い分け**
> - CSS で見た目を指定する → **class を使う**
> - ページ内リンクの飛び先、JavaScript での要素取得 → **id を使う**

### 3.2.4 子孫セレクタと複数指定

**子孫セレクタ（半角スペースでつなぐ）**

```html
<nav class="main-nav">
  <ul>
    <li><a href="#">ホーム</a></li>
  </ul>
</nav>
<p><a href="#">通常のリンク</a></p>
```

```css
.main-nav a {
  color: white;
}
```

`.main-nav` の**中にある** `<a>` だけが白くなります。
`<p>` の中の `<a>` は変わりません。

**スペースには「〜の中の」という意味がある**、と覚えてください。

```css
/* article の中の h2 の中の span */
article h2 span {
  color: red;
}
```

**複数のセレクタに同じスタイル（カンマで区切る）**

```css
h1,
h2,
h3 {
  font-family: sans-serif;
}
```

`h1` と `h2` と `h3` のすべてに適用されます。

> **よくある間違い：カンマとスペースを取り違える**
> ```css
> /* h1 の中の h2（そんなものは普通ない） */
> h1 h2 { ... }
>
> /* h1 と h2 の両方 */
> h1, h2 { ... }
> ```
> **スペースは「〜の中の」、カンマは「〜と」** です。

**その他のよく使うセレクタ**

```css
/* 直下の子だけ（孫には効かない） */
.list > li { color: red; }

/* マウスを乗せたとき */
a:hover { color: orange; }

/* リンクを訪問済み */
a:visited { color: purple; }

/* 最初の要素 / 最後の要素 */
li:first-child { font-weight: bold; }
li:last-child { border-bottom: none; }

/* すべての要素 */
* { margin: 0; }
```

`:hover` のような、状態を表すものを**擬似クラス**と呼びます。

### 3.2.5 詳細度（どれが優先されるか）

同じ要素に、複数のルールが当たることがあります。

```html
<p class="note" id="first">テキスト</p>
```

```css
p        { color: black; }
.note    { color: red; }
#first   { color: blue; }
```

**何色になるでしょうか。**

答えは **青**です。CSS には「どのルールを優先するか」の順位があり、
これを**詳細度**と呼びます。

**詳細度の順位（強い順）**

| 順位 | セレクタ | 例 | 強さ |
|------|---------|-----|------|
| 1（最強） | `style` 属性 | `<p style="...">` | 1000 |
| 2 | id セレクタ | `#first` | 100 |
| 3 | class・擬似クラス | `.note` `:hover` | 10 |
| 4（最弱） | 要素セレクタ | `p` | 1 |

セレクタを組み合わせると、点数が足し算されます。

```css
p.note        /* 1 + 10 = 11 */
.main-nav a   /* 10 + 1 = 11 */
#header .note /* 100 + 10 = 110 */
```

**点数が同じ場合は、後に書いたほうが勝ちます。**

```css
.note { color: red; }
.note { color: blue; }   /* こちらが勝つ */
```

---

> **これを踏まえた実践ルール**
>
> 1. **CSS で id を使わない**（強すぎて上書きできなくなる）
> 2. **`style` 属性を使わない**（最強なので手に負えなくなる）
> 3. **class を中心に組み立てる**（点数が揃うので、書いた順で制御できる）
>
> このルールを守るだけで、CSS のトラブルは激減します。

> **`!important` について**
> 値の後ろに `!important` を付けると、詳細度を無視して最優先になります。
>
> ```css
> .note { color: red !important; }
> ```
>
> **使わないでください。**
> 一度使うと、それを上書きするためにまた `!important` が必要になり、
> 収拾がつかなくなります。**詳細度で解決するのが正しい方法です。**

## 3.3 ボックスモデル

### 3.3.1 すべての要素は箱

**これは CSS で最も重要な考え方です。**

HTML のすべての要素は、**長方形の箱**として扱われます。
文字も画像も、見えない箱の中に入っています。

開発者ツールで確認してみましょう。

1. ページを開いて `F12`
2. 「要素」タブで、どれかの要素をクリック
3. 右側のパネルの下のほうにある**カラフルな四角い図**を見る

この図が**ボックスモデル**です。

```text
┌──────── margin（外側の余白）────────┐
│  ┌────── border（枠線）──────────┐  │
│  │  ┌─── padding（内側の余白）──┐ │  │
│  │  │                          │ │  │
│  │  │    content（中身）        │ │  │
│  │  │                          │ │  │
│  │  └──────────────────────────┘ │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

| 名前 | 意味 | たとえるなら |
|------|------|------------|
| **content** | 中身（文字や画像） | 商品 |
| **padding** | 枠線の**内側**の余白 | 箱の中の緩衝材 |
| **border** | 枠線 | 段ボール箱 |
| **margin** | 枠線の**外側**の余白 | 箱と箱の間の隙間 |

**padding と margin の違い**は、初学者が最もつまずくポイントです。
**「枠線の内か外か」** で覚えてください。

背景色を付けると違いが一目でわかります。

```css
.box {
  background-color: lightblue;
  padding: 20px;   /* 背景色が塗られる範囲が広がる */
  margin: 20px;    /* 背景色は塗られず、外に隙間ができる */
}
```

### 3.3.2 padding / border / margin

**書き方のバリエーション**

```css
/* 四方すべて同じ */
padding: 20px;

/* 上下 | 左右 */
padding: 10px 20px;

/* 上 | 左右 | 下 */
padding: 10px 20px 30px;

/* 上 | 右 | 下 | 左（時計回り） */
padding: 10px 20px 30px 40px;

/* 個別に指定 */
padding-top: 10px;
padding-right: 20px;
padding-bottom: 30px;
padding-left: 40px;
```

`margin` もまったく同じ書き方です。

> **覚え方**
> 4つ書く場合は**時計回り（上 → 右 → 下 → 左）**です。

**border（枠線）**

```css
.box {
  border: 2px solid #333;
}
```

`border` は3つの値をまとめて書きます。

```text
border: 太さ 線の種類 色;
```

| 線の種類 | 見た目 |
|---------|--------|
| `solid` | 実線 |
| `dashed` | 破線 |
| `dotted` | 点線 |
| `none` | 線なし |

一辺だけ指定することもできます。

```css
.box {
  border-bottom: 1px solid #ccc;   /* 下線だけ */
}
```

**角を丸くする**

```css
.box {
  border-radius: 8px;
}
```

```css
/* 完全な円にする（正方形の要素に対して） */
.avatar {
  width: 100px;
  height: 100px;
  border-radius: 50%;
}
```

**中央寄せの定番テクニック**

```css
.container {
  width: 800px;
  margin: 0 auto;
}
```

`margin` の左右に `auto` を指定すると、**左右の余白が自動的に均等になり、
要素が中央に配置されます。** 非常によく使うので覚えてください。

> **注意：`margin: 0 auto` は幅の指定が必要**
> `width` を指定していないと、要素が横幅いっぱいに広がってしまい、
> 中央寄せの効果が見えません。

### 3.3.3 width と box-sizing

**ここは多くの人がハマるポイントです。**

```css
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

この箱の、**画面上の実際の幅は何ピクセル**でしょうか。

初期設定では、答えは **250px** です。

```text
200px (content)
+ 20px (左 padding) + 20px (右 padding)
+  5px (左 border)  +  5px (右 border)
= 250px
```

**`width` は「中身の幅」であって、「箱全体の幅」ではないのです。**

これは非常に直感に反します。
「200px の箱を並べたつもりが、はみ出す」という事故が頻発します。

**解決策：`box-sizing: border-box`**

```css
* {
  box-sizing: border-box;
}
```

こう書くと、`width` が **「padding と border を含めた全体の幅」** に変わります。

```css
.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

これで、画面上の幅はぴったり **200px** になります。

> **実務のお約束**
> ほぼすべてのプロジェクトで、CSS の先頭に次を書きます。
>
> ```css
> * {
>   box-sizing: border-box;
> }
> ```
>
> **この本でも、以降は必ずこれを書いてある前提**で進めます。
> あなたの `style.css` の先頭にも書いておいてください。

**ページ全体の初期設定（リセット）**

ブラウザは初期状態で、`<body>` に余白を付けたり、`<h1>` に大きな `margin` を付けたりします。
これが意図しない隙間の原因になるので、最初に打ち消しておきます。

`style.css` の先頭

```css
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: sans-serif;
  line-height: 1.7;
}
```

### 3.3.4 margin の相殺

**知らないと必ずハマる仕様**を1つ紹介します。

```html
<div class="box-a">A</div>
<div class="box-b">B</div>
```

```css
.box-a { margin-bottom: 30px; }
.box-b { margin-top: 20px; }
```

A と B の間の余白は、**何ピクセル**でしょうか。

`30 + 20 = 50px` と思いきや、答えは **30px** です。

**上下に隣接する margin は、足し算されず、大きいほうだけが適用されます。**
これを **margin の相殺**（マージンの打ち消し合い）と呼びます。

> **なぜこんな仕様なのか**
> 段落が連続するとき、余白が二重にならないようにするためです。
> HTML が文書のための言語だったころの名残です。

**回避方法**

| 方法 | 説明 |
|------|------|
| **片方向だけに統一する** | 例：`margin-bottom` だけを使い、`margin-top` は使わない |
| `padding` を使う | padding は相殺しません |
| `gap` を使う | Flexbox / Grid では `gap` が使える（3.5.5） |

> **実践的なおすすめ**
> **`margin-bottom` だけを使う**と決めてしまうと、迷う場面が減ります。
> 相殺に悩まされることがなくなります。
>
> なお、**左右の margin は相殺しません。** 相殺するのは上下だけです。

## 3.4 文字と色

### 3.4.1 色の指定方法

CSS で色を指定する方法は4つあります。

**1. 色名**

```css
color: red;
color: orange;
color: skyblue;
```

約 140 種類の名前が使えます。手軽ですが、微妙な調整ができません。

**2. 16進数（最もよく使う）**

```css
color: #ff0000;   /* 赤 */
color: #00ff00;   /* 緑 */
color: #333333;   /* 濃いグレー */
color: #333;      /* 上と同じ（3桁は各桁が2回繰り返される） */
```

```text
#ff0000
 └┬┘└┬┘└┬┘
  赤 緑 青    各色を 00〜ff（0〜255）で指定
```

| 値 | 意味 |
|----|------|
| `#000000` (`#000`) | 黒 |
| `#ffffff` (`#fff`) | 白 |
| `#333333` (`#333`) | 濃いグレー（本文によく使う） |
| `#cccccc` (`#ccc`) | 薄いグレー（線によく使う） |

> **本文の色に真っ黒（`#000`）は使わない**
> 白背景に真っ黒は、コントラストが強すぎて目が疲れます。
> **`#333` 前後**を使うのが一般的です。

**3. rgb / rgba**

```css
color: rgb(255, 0, 0);          /* 赤 */
color: rgba(255, 0, 0, 0.5);    /* 半透明の赤 */
```

4つ目の値は**不透明度**（0 = 完全に透明、1 = 不透明）です。
**背景を半透明にしたいとき**によく使います。

**4. 現代的な書き方**

```css
color: rgb(255 0 0 / 50%);
```

同じ意味ですが、より新しい記法です。どちらも動きます。

**色を決めるときの道具**

VS Code では、`#333` などの色コードの左に**四角い色見本**が表示されます。
**これをクリックすると、カラーピッカーが開いて色を選べます。**

**背景色**

```css
.card {
  background-color: #f5f5f5;
}
```

`color` は文字色、`background-color` は背景色です。混同しないよう注意してください。

### 3.4.2 フォント

```css
body {
  font-family: sans-serif;
  font-size: 16px;
  font-weight: normal;
}
```

**`font-family`（書体）**

```css
font-family: "Helvetica Neue", Arial, "Hiragino Sans", "Meiryo", sans-serif;
```

**カンマ区切りで、優先順に並べます。**
「これがあれば使う、なければ次」という指定です。

最後には必ず**総称フォント**を書きます。

| 総称フォント | 意味 |
|------------|------|
| `sans-serif` | ゴシック体（線の太さが均一）。Web の標準 |
| `serif` | 明朝体（線の端に飾りがある） |
| `monospace` | 等幅（すべての文字の幅が同じ）。コード表示に使う |

> **迷ったら**
> ```css
> body {
>   font-family: sans-serif;
> }
> ```
> これだけで十分です。凝ったフォント設定は後回しで構いません。

**`font-size`（文字の大きさ）**

```css
font-size: 16px;    /* ピクセル指定 */
font-size: 1.5rem;  /* ルート要素の文字サイズの1.5倍 */
font-size: 1.2em;   /* 親要素の文字サイズの1.2倍 */
```

| 単位 | 基準 | 使いどころ |
|------|------|-----------|
| `px` | 絶対値 | わかりやすい。まずはこれで良い |
| `rem` | ルート（通常 16px）の倍数 | 全体を一括で拡大縮小できる |
| `em` | 親要素の倍数 | 入れ子で倍々になるので扱いが難しい |

**この本では `px` を使います。** `rem` は慣れてから使ってください。

**`font-weight`（太さ）**

```css
font-weight: normal;   /* = 400 */
font-weight: bold;     /* = 700 */
font-weight: 300;      /* 細い（フォントが対応していれば） */
```

### 3.4.3 行間・字間・揃え

**`line-height`（行間）— 読みやすさに最も影響する**

```css
body {
  line-height: 1.7;
}
```

**単位なしの数値**で指定します。「文字サイズの何倍の高さにするか」という意味です。

| 値 | 印象 |
|----|------|
| `1.0` | 詰まっていて読みにくい |
| `1.5` 〜 `1.8` | **日本語の本文に適切** |
| `2.0` 以上 | 間延びして見える |

> **日本語は英語より広めの行間が必要です。**
> 漢字の画数が多く、詰まって見えるためです。`1.7` 前後にしておくと安全です。

**`text-align`（横方向の揃え）**

```css
text-align: left;     /* 左揃え（デフォルト） */
text-align: center;   /* 中央揃え */
text-align: right;    /* 右揃え */
```

> **よくある勘違い**
> `text-align: center` は、**中の文字を中央に揃える**指定です。
> **箱そのものを中央に置く**ものではありません。
> 箱を中央に置きたいときは `margin: 0 auto`（3.3.2）か Flexbox（3.5）を使います。

**その他**

```css
letter-spacing: 0.05em;        /* 字間 */
text-decoration: underline;    /* 下線 */
text-decoration: none;         /* 下線を消す（リンクによく使う） */
```

**リンクの見た目を整える定番**

```css
a {
  color: #0066cc;
  text-decoration: none;
}

a:hover {
  text-decoration: underline;
}
```

「普段は下線なし、マウスを乗せたら下線」という、よくある指定です。

## 3.5 レイアウト

ここからが第3章の本番です。**要素を横に並べる**方法を学びます。

### 3.5.1 display の基本

2.5.1 で、タグには**ブロック**と**インライン**の2種類があると学びました。
この性質は、CSS の `display` プロパティで変更できます。

```css
.item {
  display: block;
}
```

| 値 | 性質 |
|----|------|
| `block` | 横幅いっぱいに広がる。前後で改行。`width` / `height` が効く |
| `inline` | 中身の分だけの幅。改行しない。**`width` / `height` が効かない** |
| `inline-block` | 改行しないが、`width` / `height` が効く |
| `none` | **表示されなくなる**（場所も取らない） |
| `flex` | **子要素を横に並べる**（次項） |
| `grid` | 子要素を格子状に並べる |

> **`display: none` の使いどころ**
> 「特定の条件のときだけ隠す」という場面でよく使います。
> JavaScript から切り替えることもできます（第5章）。

> **`<a>` にサイズを指定したいとき**
> `<a>` はインラインなので、そのままでは `width` が効きません。
> ボタン風にしたいときは `display: inline-block;` か `display: block;` を指定します。

### 3.5.2 Flexbox の考え方

**Flexbox** は、要素を並べるための仕組みです。
**現在の Web 制作で最もよく使う技術**なので、しっかり理解してください。

使い方は、**並べたい要素たちの「親」に、`display: flex` を書く**——これだけです。

```html
<div class="container">
  <div class="item">A</div>
  <div class="item">B</div>
  <div class="item">C</div>
</div>
```

```css
.container {
  display: flex;
}

.item {
  background-color: lightblue;
  padding: 20px;
  border: 1px solid #333;
}
```

```text
display: flex なし（初期状態 — div はブロックなので縦に並ぶ）
┌───────────────┐
│ A             │
├───────────────┤
│ B             │
├───────────────┤
│ C             │
└───────────────┘

display: flex あり
┌───┬───┬───┐
│ A │ B │ C │
└───┴───┴───┘
```

**重要な用語**

| 用語 | 意味 |
|------|------|
| **Flex コンテナ** | `display: flex` を指定した**親**要素 |
| **Flex アイテム** | その**直接の子**要素 |
| **主軸**（main axis） | 並ぶ方向。初期状態は**横** |
| **交差軸**（cross axis） | 主軸と垂直な方向。初期状態は**縦** |

> **ここを間違えないでください**
> `display: flex` は、**並べたい要素そのものではなく、その親に書きます。**
> 初学者が最もよくやる間違いです。

**並ぶ方向を変える**

```css
.container {
  display: flex;
  flex-direction: row;      /* 横（初期値） */
}
```

| 値 | 方向 |
|----|------|
| `row` | 左から右（初期値） |
| `row-reverse` | 右から左 |
| `column` | 上から下 |
| `column-reverse` | 下から上 |

> **`flex-direction: column` を指定すると、主軸が縦になります。**
> このとき、次に説明する `justify-content` も**縦方向**の指定になります。
> ここが Flexbox の最大の混乱ポイントです。

### 3.5.3 主軸方向の配置（justify-content）

**主軸の方向**に、アイテムをどう配置するかを決めます。
初期状態（`row`）では**横方向**の配置です。

```css
.container {
  display: flex;
  justify-content: center;
}
```

```text
flex-start（初期値）    左に寄る
┌─────────────────────┐
│ A  B  C             │
└─────────────────────┘

center                中央に寄る
┌─────────────────────┐
│       A  B  C       │
└─────────────────────┘

flex-end              右に寄る
┌─────────────────────┐
│             A  B  C │
└─────────────────────┘

space-between         両端に寄せて、間を均等に
┌─────────────────────┐
│ A        B        C │
└─────────────────────┘

space-around          各要素の左右に均等な余白
┌─────────────────────┐
│   A     B     C     │
└─────────────────────┘

space-evenly          すべての隙間を均等に
┌─────────────────────┐
│    A    B    C      │
└─────────────────────┘
```

> **`space-between` はヘッダーの定番**
> 「左にロゴ、右にメニュー」という配置は、これ1行で作れます。
>
> ```css
> .header {
>   display: flex;
>   justify-content: space-between;
> }
> ```

### 3.5.4 交差軸方向の配置（align-items）

**交差軸の方向**の配置を決めます。
初期状態（`row`）では**縦方向**の配置です。

```css
.container {
  display: flex;
  align-items: center;
  height: 200px;
}
```

| 値 | 意味 |
|----|------|
| `stretch` | **高さを揃えて引き伸ばす**（初期値） |
| `flex-start` | 上に揃える |
| `center` | **上下中央に揃える** |
| `flex-end` | 下に揃える |
| `baseline` | 文字の下端（ベースライン）で揃える |

> **CSS の永遠の課題「上下中央揃え」が、これで解決します**
>
> ```css
> .container {
>   display: flex;
>   justify-content: center;   /* 左右中央 */
>   align-items: center;       /* 上下中央 */
>   height: 300px;
> }
> ```
>
> **この3行で、中の要素が完全に中央に配置されます。**
> Flexbox が登場する前は、これが非常に困難でした。覚えておいて損はありません。

**`justify-content` と `align-items` の覚え方**

| プロパティ | 方向（`flex-direction: row` のとき） |
|-----------|-----------------------------------|
| `justify-content` | **横**（主軸） |
| `align-items` | **縦**（交差軸） |

`flex-direction: column` にすると、この2つが**入れ替わります**。
「主軸か、交差軸か」で覚えるのが正解です。

### 3.5.5 折り返しと隙間

**`gap`（アイテム間の隙間）**

```css
.container {
  display: flex;
  gap: 20px;
}
```

アイテムとアイテムの間に、20px の隙間が入ります。

> **`margin` より `gap` を使ってください**
> `margin` だと「最後の要素にだけ余白が余る」問題が起きますが、
> `gap` は**要素と要素の間にだけ**入るので、この問題が起きません。
> **margin の相殺（3.3.4）にも悩まされません。**

**`flex-wrap`（折り返し）**

初期状態では、アイテムは**折り返さずに縮みます**。
画面が狭くなると、中身が潰れて読めなくなります。

```css
.container {
  display: flex;
  flex-wrap: wrap;
}
```

`wrap` を指定すると、**入りきらないアイテムが次の行に折り返します。**

> **カードを並べるときの定番**
>
> ```css
> .card-list {
>   display: flex;
>   flex-wrap: wrap;
>   gap: 20px;
> }
>
> .card {
>   width: 300px;
> }
> ```
>
> 画面幅に応じて、3列 → 2列 → 1列と自動的に変わります。

**`flex-grow` / `flex-shrink`（伸び縮み）**

```css
.sidebar {
  width: 200px;
  flex-shrink: 0;    /* 縮まない */
}

.main-content {
  flex-grow: 1;      /* 余ったスペースを全部もらう */
}
```

「サイドバーは 200px 固定、本文が残り全部」というレイアウトが作れます。

| プロパティ | 意味 |
|-----------|------|
| `flex-grow: 1` | 余ったスペースを分け合う |
| `flex-grow: 0` | 伸びない（初期値） |
| `flex-shrink: 0` | 縮まない |
| `flex-shrink: 1` | 縮む（初期値） |

### 3.5.6 Grid にざっと触れる

Flexbox が**1方向**（横または縦）に並べるのに対し、
**Grid** は**2方向**（行と列）の格子状に並べます。

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
```

```text
┌─────┬─────┬─────┐
│  A  │  B  │  C  │
├─────┼─────┼─────┤
│  D  │  E  │  F  │
└─────┴─────┴─────┘
```

| 記述 | 意味 |
|------|------|
| `grid-template-columns` | 列の定義 |
| `repeat(3, 1fr)` | 「1fr の列を3つ」の意味 |
| `1fr` | 余ったスペースを等分する単位（**fr**action = 分数） |

**画面幅に応じて自動で列数が変わる書き方**

```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 20px;
}
```

「最低 280px を確保しつつ、入るだけ列を作る」という指定です。
**メディアクエリなしでレスポンシブになる**ので、非常に便利です。

> **使い分けの目安**
> - 横一列に並べる、中央揃え → **Flexbox**
> - カードを格子状に並べる、複雑なページ全体の骨組み → **Grid**
>
> **まずは Flexbox を確実に使えるようになってください。**
> Grid は必要になったときに調べれば十分です。

## 3.6 レスポンシブ対応

### 3.6.1 スマホで見るとどうなるか

現在、Web サイトへのアクセスの多くはスマートフォンからです。
**パソコンで作ったページが、スマホで崩れていないか**を確認する必要があります。

**確認方法（開発者ツール）**

1. ページを開いて `F12`
2. 開発者ツールの左上にある**スマホとタブレットのアイコン**をクリック
   （または `Ctrl` + `Shift` + `M` / macOS: `command` + `shift` + `M`）
3. 上部のドロップダウンから機種を選ぶ（iPhone など）

画面がスマホサイズになり、実機で見た状態を再現できます。

### 3.6.2 viewport の設定

**これがないと、レスポンシブ対応は一切効きません。**

```html
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
</head>
```

| 記述 | 意味 |
|------|------|
| `width=device-width` | ページの幅を、端末の画面幅に合わせる |
| `initial-scale=1.0` | 初期の拡大率を等倍にする |

これを書かないと、スマホは「幅 980px の画面」として描画してから縮小表示します。
結果、**文字が極端に小さくなります。**

> **VS Code の `!` + `Tab` で出る骨組みには、これが最初から含まれています。**
> 消さないでください。

### 3.6.3 メディアクエリ

**画面幅によって CSS を切り替える**仕組みです。

```css
/* 通常（すべての画面幅に適用） */
.container {
  display: flex;
  gap: 20px;
}

/* 画面幅が 768px 以下のときだけ適用 */
@media (max-width: 768px) {
  .container {
    flex-direction: column;
  }
}
```

パソコンでは横並び、スマホでは縦並びになります。

**書き方**

```css
@media (max-width: 768px) {
  /* 768px 以下のときのスタイル */
}

@media (min-width: 769px) {
  /* 769px 以上のときのスタイル */
}
```

**よく使う区切り幅（ブレイクポイント）**

| 幅 | 想定端末 |
|----|---------|
| 480px 以下 | スマートフォン |
| 768px 以下 | タブレット（縦） |
| 1024px 以下 | タブレット（横）・小さいノートPC |

> **モバイルファースト**
> 実務では、**スマホ向けの CSS を基本として書き、
> `min-width` で画面が広いときの指定を追加していく**書き方が主流です。
>
> ```css
> /* スマホ用（基本） */
> .container {
>   flex-direction: column;
> }
>
> /* 769px 以上のとき */
> @media (min-width: 769px) {
>   .container {
>     flex-direction: row;
>   }
> }
> ```
>
> スマホのほうがレイアウトが単純なので、こちらを基本にしたほうが CSS が短くなります。

**画像がはみ出さないようにする**

```css
img {
  max-width: 100%;
  height: auto;
}
```

**これは必ず書いてください。**
大きな画像がスマホ画面からはみ出して、横スクロールが発生するのを防ぎます。

## 3.7 CSS が効かないときの調べ方

**CSS が効かないときは、次の順番で確認してください。**
この手順を覚えると、自分で解決できる割合が大きく上がります。

**ステップ1：CSS ファイルが読み込まれているか**

`F12` →「ネットワーク」タブ → ページを再読み込み。
`style.css` の行を探して、ステータスが `200` になっているか確認します。

`404` なら、**`<link href="...">` のパスが間違っています。**

もっと簡単な確認方法もあります。CSS の先頭に次を書いてみてください。

```css
body {
  background-color: pink;
}
```

**背景がピンクにならなければ、CSS ファイル自体が読み込まれていません。**

**ステップ2：セレクタが合っているか**

`F12` →「要素」タブ → 効かせたい要素をクリック。
右側の「スタイル」パネルに、自分が書いたルールが表示されているか確認します。

**表示されていない → セレクタが間違っています。**

よくある間違い：

| 間違い | 正しい |
|--------|--------|
| `note { }`（ドット忘れ） | `.note { }` |
| `.Note`（大文字小文字違い） | `.note` |
| HTML 側が `class="notes"` | 名前を一致させる |
| `.menu a`（`.menu` の外にある `a`） | 構造を確認する |

**ステップ3：他のルールに上書きされていないか**

「スタイル」パネルで、**自分のルールに取り消し線が引かれていないか**見てください。

```text
.note {
  color: red;        ← 取り消し線が引かれている
}
```

取り消し線 = **他のルールに負けている**、という意味です。
詳細度（3.2.5）を確認してください。

**ステップ4：値やプロパティ名の書き間違い**

```css
.box {
  colour: red;        /* ❌ color の綴り間違い */
  width: 100;         /* ❌ 単位がない */
  background: #gg0000; /* ❌ 16進数にない文字 */
}
```

**開発者ツールでは、無効な行に警告マーク（⚠）が表示されます。**

**ステップ5：保存とキャッシュ**

| 確認 | 対処 |
|------|------|
| CSS ファイルを保存したか | `Ctrl` + `S` |
| ブラウザを再読み込みしたか | `F5` |
| 古い CSS がキャッシュされている | **`Ctrl` + `Shift` + `R`**（強制再読み込み） |

> **キャッシュは本当によく起きます**
> ブラウザは、一度読んだ CSS を保存して使い回します（キャッシュ）。
> 「直したはずなのに変わらない」ときは、
> **`Ctrl` + `Shift` + `R`**（macOS: `command` + `shift` + `R`）を試してください。

> **つまずいたら**
> ```text
> react-text の 3.5.3 で、要素が横に並びません。
>
> 【HTML】
> （該当部分を貼る）
>
> 【CSS】
> （該当部分を貼る）

## まとめ

- CSS は**見た目**を指定する言語。HTML（意味）と分けて別ファイルに書く
  - `<link rel="stylesheet" href="style.css" />` を `<head>` に書く
- ルールの構造：`セレクタ { プロパティ: 値; }`。**セミコロン必須**
- セレクタ：要素（`p`）、class（`.note`）、id（`#header`）
  - **CSS では class を中心に使う。id と `!important` は使わない**
  - スペースは「〜の中の」、カンマは「〜と」
  - **詳細度**：style属性 > id > class > 要素。同点なら後勝ち
- **ボックスモデル**：content → padding → border → margin
  - padding は枠線の**内**、margin は枠線の**外**
  - **`box-sizing: border-box` を最初に書く**
  - 上下の margin は**相殺**する。`margin-bottom` だけを使うと楽
  - `margin: 0 auto` で中央寄せ（`width` の指定が必要）
- 色は `#333` のような16進数が主流。本文に真っ黒は使わない
- `line-height: 1.7` 前後が日本語の本文に適切
- **Flexbox**：**親**に `display: flex`
  - `justify-content` = 主軸（初期状態では横）
  - `align-items` = 交差軸（初期状態では縦）
  - **この2つを `center` にすると完全な中央揃え**
  - `gap` で隙間、`flex-wrap: wrap` で折り返し
- レスポンシブ：**`<meta name="viewport">` が必須**
  - `@media (max-width: 768px) { }` で画面幅による切り替え
  - `img { max-width: 100%; }` は必ず書く
- CSS が効かないときは、**3.7 の5ステップ**で切り分ける

### 演習 3.2 ★★☆ カードを横に並べる

**課題**
次の HTML に CSS を当てて、3枚のカードを横並びにしてください。

```html
<div class="card-list">
  <div class="card">
    <h3>1時間プラン</h3>
    <p>1,200円</p>
  </div>
  <div class="card">
    <h3>2時間プラン</h3>
    <p>2,000円</p>
  </div>
  <div class="card">
    <h3>フリープラン</h3>
    <p>3,000円</p>
  </div>
</div>
```

**完成条件**
- 3枚のカードが横に並んでいる
- カード同士の間に 20px の隙間がある
- 各カードに枠線と、内側の余白（padding）がある
- 各カードの角が丸くなっている
- カードの幅が揃っている
- **ブラウザの幅を狭めると、入りきらないカードが下に折り返される**

**ヒント**
`display: flex` を書くのは `.card-list` と `.card` のどちらでしょうか。
折り返しには `flex-wrap` が必要です。

### 演習 3.3 ★★☆ ヘッダーを作る

**課題**
次のようなヘッダーを作ってください。

```text
┌──────────────────────────────────────────┐
│  にゃんこ           ホーム メニュー アクセス  │
└──────────────────────────────────────────┘
```

**完成条件**
- 左側にサイト名（`<h1>`）、右側にナビゲーション（`<nav>`）がある
- 両者が左右の端に寄っている

- リンクの下線が消えており、マウスを乗せると色が変わる
- ヘッダーに背景色と、上下の padding がある

**ヒント**
Flexbox を**2箇所**で使います。1つはヘッダー全体、もう1つはナビゲーションの中です。
`<ul>` の点（`・`）を消すには `list-style: none;` を使います。
